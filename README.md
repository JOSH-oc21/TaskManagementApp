# Task Management App

This repository contains a .NET MAUI Blazor Hybrid Task Management App created for a final project assignment.

## Features
- Add tasks
- Edit tasks
- Delete tasks
- Mark tasks as complete or pending
- Filter tasks by status
- Local JSON persistence using app storage
- Simple dashboard summary

## Requirements
- .NET 8 SDK
- Visual Studio 2022 with MAUI workload or VS for Mac
- Android SDK for emulator/device testing

## Run the app
1. Open the solution in Visual Studio.
2. Set the project as the startup project.
3. Choose an Android emulator or connected device.
4. Press F5 to run.
